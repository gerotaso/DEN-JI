# 顧客管理・はがき宛名印刷 Prototype

## 起動
1. `index.html` を Chrome または Edge で開く
2. 「CSVを開く」で `customer.csv` を選択
3. 一覧から顧客をクリックすると編集できます
4. 「新規登録」「CSVを保存」でデータを管理できます
5. 一覧の「印刷」チェックを選び、「はがき宛名PDF」を押す
6. 「印刷 / PDF保存」でブラウザの印刷画面を開く
7. PDFに保存する場合はプリンター選択で「PDFに保存」
8. 実物のはがきへ印刷する場合は、用紙サイズを「はがき」、倍率を「100% / 実際のサイズ」にしてください

## 注意
- Chrome / Edge の File System Access API が使える環境では、選択したCSVを元のファイルへ保存できます。
- 環境によっては「名前を付けて保存」になります。
- はがきの宛名位置はプロトタイプ用の仮設定です。実機でテストして位置を調整してください。
- CSVの列名を変更するとフォーム表示も変わります。基本列は
  id,name,company,postal_code,address,tel,email,note
  です。
